# Chocolate Sales Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard built to analyze chocolate sales performance across products, customers, stores, and regions. The dashboard provides insights into revenue, profit, sales trends, customer behavior, and product performance to support data-driven business decisions.

## Dataset

* Source: Kaggle Chocolate Sales Dataset
* Period Covered: 2023–2024
* Records: 1M+ sales transactions
* Data Tables: Sales, Customers, Products, Stores, and Calendar

## Tools Used

* Power BI
* SQL
* Power Query
* Data Modeling
* Data Visualization

## Key Features

* Sales and Profit Performance Analysis
* Product Category and Brand Analysis
* Customer Demographic Insights
* Store and Regional Performance Tracking
* Monthly and Yearly Sales Trend Analysis
* Interactive Filters and Drill-Down Reports

## Business Insights

* Identified top-performing products and categories.
* Analyzed customer purchasing behavior across demographics.
* Evaluated store-level and regional sales performance.
* Tracked revenue and profit trends over time.
* Highlighted opportunities for improving sales and profitability.

## Dashboard Pages

1. Executive Summary
2. Sales Performance Analysis
3. Product Performance Dashboard
4. Customer Insights Dashboard
5. Store Performance Dashboard

## Project Outcome

The dashboard transforms raw sales data into actionable insights, helping stakeholders monitor KPIs, identify trends, and make informed business decisions.
